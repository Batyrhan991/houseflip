# House Flip 3D

Браузерная 3D-игра в жанре симулятора ремонта домов, вдохновленная **House Flipper**.

### Особенности игры:
- Полное 3D окружение на Three.js.
- Инструменты для уборки мусора и покраски стен.
- Экономика: зарабатывайте деньги и прокачивайте опыт за ремонт.
- Возможность продать отремонтированный дом и заработать состояние.

### Управление:
- **WASD** — перемещение по дому.
- **Мышь** — осмотр.
- **ЛКМ** — взаимодействие (убрать мусор, покрасить стену).
- Панель внизу экрана для переключения инструментов.
